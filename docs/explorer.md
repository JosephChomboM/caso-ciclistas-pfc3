# Explorador y navegación

El explorador conserva mapa, lista sincronizada, filtros, detalle con fuente, reportes publicados y favoritos personales. Los filtros se obtienen del catálogo cargado para evitar distritos o condiciones sin respaldo.

El footer enlaza el mapa, el repositorio y el perfil GitHub de Joseph. No se inventan perfiles sociales. Se retiró el aviso grande de la cabecera a solicitud de Joseph; la fuente de cada registro y la sección Datos y alcance conservan la identificación del catálogo académico.
